# 工训电类物联网系统小车

基于 STC 单片机的智能小车与停车场道闸综合项目，2025-2026 学年工程训练课程作业。

## 项目简介

项目分为两大模块：**智能小车**（蓝牙遥控 + 自动循迹 + RFID 识别）和**停车场道闸系统**（红外检测 + 舵机抬落杆 + 语音播报），两者通过蓝牙/串口通信联动，模拟真实物联网场景。

## 项目结构

```
├── 个人任务/          # 每人独立完成的基础功能模块
├── 团队任务/          # 多人协作集成的完整系统
├── 蓝牙控制/          # 蓝牙调试 APK 与说明文档
├── 2026新小车程序低配小车控制/   # 早期小车控制版本
└── STC大礼包2025/     # 开发工具包（Keil5、STC-ISP 等）
```

## 个人任务

每位同学独立完成一个功能模块，基于 STC8H 或 STC15W 单片机，使用 Keil C51 开发。

**组员1**

- 主控板道闸程序：舵机驱动道闸抬杆/落杆，红外传感器检测车辆，TM1650 数码管显示，SYN6288 语音播报，红绿灯状态指示，含按键手动控制
- 蓝牙遥控小车程序：双电机差速驱动（前进/后退/左转/右转/停止），三路红外循迹，超声波测距避障，光敏电阻检测红绿灯，蓝牙串口接收遥控指令
- 蓝牙调试器 APK：Android 端蓝牙串口调试工具，用于测试小车无线通信

**组员2**

- 智能小车程序框架：电机驱动、红外循迹、超声波避障、红绿灯识别、SYN6288 语音播报、蓝牙/RFID 通信接收

**组员3**

- 红绿灯程序框架（新）：基于 STC15W408AS，双位数码管倒计时显示，红/黄/绿灯状态切换，绿灯 10s -> 黄灯 3s -> 红灯 12s 循环，支持夜间黄灯闪烁模式和 RS485 串口通信
- 主控板程序框架(入口)：停车场入口道闸控制，四状态状态机（空闲/抬杆/通行/落杆），红外车辆检测，舵机 PWM 控制，SYN6288 语音播报，数码管显示

## 团队任务

在个人模块基础上进行系统集成，调试联调，形成可演示的完整方案。

**2. 停车场（闸机）**
- 入口道闸：红外检测车辆到达 -> 语音播报 -> 舵机抬杆 -> 车辆通过后自动落杆，支持按键手动控制
- 出口道闸：与入口对称，完成车辆驶出检测与落杆逻辑
- 入口/出口之间通过串口通信联动，共享车位状态

**3. 智能小车程序框架 latest**
- 集成循迹、避障、红绿灯识别、RFID 标签识别和蓝牙遥控，实现小车的自动行驶与停车逻辑
- 小车检测到 RFID 标签时语音播报对应编号，并根据指令停车或继续行驶
- 光敏电阻识别红绿灯：红灯停、绿灯行
- 与道闸系统联动：小车到达入口时触发道闸抬杆，通过后自动落杆

## 硬件平台

- 主控：STC8H3K64S4 / STC15W408AS
- 电机驱动：L298N 双路驱动
- 传感器：红外循迹模块、超声波 HC-SR04、光敏电阻
- 通信：KT6368A 蓝牙模块、RS485 串口
- 语音：SYN6288 语音合成模块
- 显示：TM1650 四位数码管
- 舵机：SG90（道闸抬杆）
- 开发工具：Keil uVision5、STC-ISP v6.94D
